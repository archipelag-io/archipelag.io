# Web fonts

This directory contains the WOFF2 files used by the public site so page rendering does not depend on third-party font requests.

- Satoshi and Sora: distributed by [Fontshare](https://www.fontshare.com/) under the Fontshare free-font license.
- IBM Plex Mono: distributed by IBM under the SIL Open Font License 1.1.

Only the weights used by the site are included.
