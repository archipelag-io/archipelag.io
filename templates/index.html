The idea

AI inference, without the faraway data center

Lots of capable hardware sits idle in homes, offices, and labs. Archipelag.io connects it into one network and sends each request to a good match nearby.

Nearby, not far away

Each request goes to a capable machine close to you, so answers start streaming sooner and your data travels a shorter path.

Safe for both sides

Islands only run reviewed, signed model packages inside a sandbox — never arbitrary code. You can limit which regions your requests may run in.

A fair market, tested first

Island operators set an asking price and Consumers set a budget. During Phase 2 that market runs on free virtual credits, so it can be tuned before real money is involved.

Questions

The honest answers

Still curious? Read the current status page or email us.

Is it really free?

Yes, during Phase 2. Every account gets virtual credits with no cash value, and no payment method is needed. Balances may be refilled or reset while we validate metering.

Can I earn money by running an Island?

Not yet. Islands earn virtual credits for completed Jobs so we can test matching and accounting. Real-money payouts are not enabled; the status page is the source of truth for when that changes.

Is it safe to run an Island on my computer?

The Island software only runs approved, signed Cargos, inside containers with seccomp profiles, resource limits, and network controls. It never runs code submitted by Consumers. You are still responsible for keeping the machine itself patched and secure.

Who can see my prompts?

Your request is processed by the Island that runs it, and passes through the Coordinator. Treat Phase 2 like any shared beta: don’t send sensitive, regulated, or confidential data. Confidential inference is a research prototype, not a guarantee.

Does my data stay in my region?

Jobs prefer nearby Islands by default, and you can attach a regional placement policy that limits where a Job may run. The Coordinator records which Island ran it. These controls support data-residency programs but are not a legal compliance guarantee on their own.

Do I need to change my code?

Usually only the base URL and API key. The chat endpoint follows the OpenAI format, including streaming. Check the API reference for the parameters your integration relies on.

Under the hood

Built on boring, reliable technology

No blockchain, no token. Open-source software you can read.

One request, one dependable path: coordinate, dispatch, execute, stream back.

01 Control plane Elixir / Phoenix

The Coordinator handles placement, accounting, and health. Elixir supervision isolates failures and keeps concurrent Job state manageable.

02 Messaging NATS JetStream

NATS carries Job dispatch and streamed output. JetStream acknowledgements support retry and requeue when an Island disappears.

03 Island software Rust / Tokio

A lightweight binary that manages Cargo runtimes, reports heartbeats, and streams output back to the Coordinator.
