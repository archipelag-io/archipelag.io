03 — Workflows

Chain models into pipelines Experimental

Experimental workflow definitions use DAGs. The Coordinator resolves dependencies, dispatches steps in parallel across Islands, maps data between steps, and merges results.

Translate text, classify the output, then summarize — all in one API call. Each step can run on a compatible Island, with retry or abort behavior defined per step.

  • DAG-based dependency resolution — steps run in parallel when possible
  • Data mapping between steps via templates
  • Built-in failure handling — retry, skip, or abort per step
  • Same API — submit a workflow definition, get merged results
04 — Advanced Capabilities

Beyond inference

Experimental capabilities under active validation. Interfaces and guarantees may change during Phase 2.

Inference Caching Experimental

Reuse eligible results without repeating compute

  • Cache hits are instant and free — no Island compute used
  • Semantic matching catches near-duplicates (not just exact text)
  • Can reduce latency and duplicated compute for repetitive Jobs
  • Per-Cargo eligibility and opt-out controls are being tested

A/B Testing Experimental

Compare model versions with real traffic

  • Split traffic between model variants (80/20, 50/50, etc.)
  • Track latency, success rate, and throughput per variant
  • Statistical significance with p-values and confidence intervals
  • Auto-promote the winner when results are conclusive

Federated Fine-Tuning Experimental

Train models without centralizing data

  • Participating Islands train against locally held datasets
  • Model updates are aggregated instead of collecting source datasets
  • Differential privacy for mathematical data protection
  • Not a compliance guarantee; organizations must validate their own use case

Confidential Inference Experimental

Stronger isolation on supported attested hardware

  • TEE hardware attestation (Intel SGX, AMD SEV, ARM TrustZone)
  • Payload encryption outside the attested execution boundary
  • Availability depends on Island hardware and current attestation state
  • Use only after validating the experimental threat model
